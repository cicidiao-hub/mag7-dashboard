交易铁律 (常见流派红线 · 参考)

🛑 止损铁律

  • O'Neil 7% 法：买入价跌 7% 无条件清仓，永不破例
  • ATR 法：跌破 入场价 − 2×ATR(14)
  • 技术法：跌破 MA50 或前期重要支撑
  • 时间法：3 月未明显趋势 → 退出找更好标的

💰 止盈分批

  • +20% 卖 1/3 锁利
  • +50% 再卖 1/3
  • 剩余 用 trailing stop 跟高点 −10%
  • 到分析师目标价附近优先减仓而非追涨

📊 仓位红线

  • 单只 ≤ 10% (集中仓 Buffett 风格)，5% (分散)
  • 单板块 ≤ 30%，避免行业塌方
  • 现金保留 ≥ 10% 应对回调
  • 禁用杠杆炒个股，禁裸卖期权

⛔ 操作禁区

  • 不补亏损股 (Don't average down)
  • 不接飞刀：单日跌 >5% 当日不抄底
  • 财报前减仓至 1/2，避免单日 20% 波动
  • 连续两季盈利下滑 → 退出
